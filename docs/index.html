Not connecting?

Office, school and mall Wi-Fi often stop phones from talking to each other. Turn on one phone’s hotspot and connect the other phone to it, then try again.

Use Chrome on both phones and keep both screens on while you scan. If a scan fails, copy the code and send it through Messenger or Viber, then paste it.
